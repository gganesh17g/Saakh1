# Payroll and GST readiness research

Last reviewed: **28 October 2026**. This is an implementation boundary record, not legal/tax advice or a certification. All automated payroll rates are effective-dated administrator assumptions with preserved labels/source notes; the seed rule is explicitly zero-rate illustrative data, not a legal exemption. No jurisdiction-specific statutory rate or threshold is silently installed as current law.

Research informs explicit omissions and configuration boundaries, not a compliance badge. Before real deployment, professional payroll/GST review must establish applicable laws, current notifications/effective dates and test cases per establishment/employee/state/taxpayer. Then use versioned verified rule packages, server-side protected data and approved payment/statutory providers. No real salary transfers or remittances are performed here.
