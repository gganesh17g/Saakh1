# Feature behavior

| Feature                | Implemented behavior                                                                                 | Boundary                                                         |
| ---------------------- | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Financial digital twin | Edit financial assumptions and rerun all engines                                                     | No real bank twin                                                |
| Time machine           | Scrub 12 historical / 12 future periods, revenue/cash readout, chart marker and graph-flow highlight | Historical network topology is fixed                             |
| Decision X-ray         | Select factor for formula, inputs, contribution, availability and prior-run delta                    | No calibrated attribution model                                  |
| Parallel universes     | Baseline and up to 3 independently calculated draft snapshots                                        | Draft comparison state is session-only                           |
| Score improvement      | Live same-engine score sensitivity in borrower editor                                                | No optimization advice or record manipulation                    |
| Evidence constellation | Click borrower/rule/transaction/invoice chains and alert evidence                                    | Compact linked explorer, not a second WebGL scene                |
| Human review           | Record queue, notes, evidence status, unresolved questions and draft assessment                      | Browser-local, no automatic decision                             |
| Confidence radar       | Source availability grid and weighted coverage metric                                                | Not a statistical confidence probability or geometric radar plot |
| Story mode             | Five skippable checkpoints with live route overlays and contextual highlights                        | Live route overlays and checkpoint highlights; no fake video     |
| Replay/history         | Saved input snapshots, stage scrubber, restore and exports                                           | Stage inspection, not recalculation animation                    |

Five primary pages and four secondary routes work. The public site includes a live surplus sensitivity teaser and links to complete calculations. Original branding and layout use Navadhan only as high-level inclusion inspiration.

Native HTML controls support keyboard navigation; WebGL relationships also have button inspection and an SVG alternative. Theme cycles dark/light/system and persists locally. Reduced motion starts graph rotation/data flow paused. Print report can be saved as PDF through browser print UI; no dedicated PDF library or silent PDF download is included.
