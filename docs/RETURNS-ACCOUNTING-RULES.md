# Quantity returns and accounting · operations-paise-1

Both return types reuse original documents, original line prices/discounts/tax, original standard-cost stock evidence, the common postJournal function, credits collection, audit records and atomic persistence. Draft quantities reserve eligibility; rejected/reversed returns release it. Multiple partial returns allocate line net/tax/stock cost cumulatively to avoid final rounding drift. No return can exceed original quantities less reserved/committed returns. A document with legacy amount-based credits is excluded from new quantity returns until reviewed; no unsupported historical quantities are invented.

Sales: Draft → Submitted → Needs Review/Approved/Rejected → Credit Issued → Closed; committed returns can be reversed after all active settlements are reversed and restored sellable stock is still available. Approval itself has no journal or stock movement. Credit issuance records the received/inspected goods event: Dr revenue adjustment and entered output tax; Cr receivable up to unpaid balance, remainder Cr customerCredit liability. Credit notes are unique SR IDs. Sellable items restore available units and Dr inventory / Cr costOfSales using snapshotted cost. Quarantine holds separate quarantineInventory value and no sellable units; Write off restores neither available stock nor inventory value and leaves original cost in costOfSales. Condition/quantity evidence remains on the return.

Purchase: Draft → Submitted → Approved → Goods Dispatched → Awaiting Supplier Credit → Supplier Credit Received → Settled/Closed. Approval alone changes neither stock nor cash. Dispatch removes available units: Dr returnsPending asset / Cr inventory at original standard cost. Supplier credit requires an externally supplied reference entered by the user. Partial credit receipts allocate original net, entered input tax and pending stock cost cumulatively; each reference is recorded once. Dr payable up to bill due, excess Dr supplierCredit asset; Cr returnsPending/inputGST and adjust the original purchase expense variance. An internal PR document is labeled an acknowledgment, never a supplier-issued credit note. Disputes/communication are recorded and disputed expected refunds are excluded from the cash forecast.

Both: refund preference is distinct from credit; only a separately confirmed recorded refund changes bank. Sales refund Dr customerCredit / Cr bank; supplier refund Dr bank / Cr supplierCredit. Partial refunds cannot exceed available credit. Credit allocation only targets outstanding documents of the same counterparty/type and changes receivable/payable with no cash. Refund/allocation reversal posts opposite lines, marks the settlement reversed and restores the credit. Original return/source/journal/audit evidence remains. Active return credit received = applied + refunded + available credit, checked before persistence. Physical quantity, accounting amount and cash events are distinct.

Legacy creditReturn remains readable/tested for historical records, including its explicit immediate-refund semantics; the primary UI now directs new returns through separate approval/credit/refund events. GST amounts are user-entered illustrative adjustments, not verified input-tax entitlement, statutory credit-note reporting or GST compliance.
