# Saakh 3.0 known limitations

- Synthetic, browser-local demonstration. Role views (owner, accountant, payroll, manager, staff, auditor, admin) simulate permissions and hide unrelated payroll UI; anyone controlling browser storage can inspect/edit it. No secure production accounts, encrypted tenant database or tamper-proof audit is claimed. Use fictional employee/customer data only.
- Monthly payroll and integer attendance/overtime units. Mid-month salary changes for existing employees explicitly require an unsupported split-period review; they are blocked. Calendar-day joining proration, manual leave entitlement, bonuses and deductions are illustrative policies. No statutory eligibility, minimum wage, EPS split, ESI continuation, automatic professional-tax/TDS slabs, filings or remittances.
- Stock uses existing standard-cost policy, not FIFO/lot tracking. Quarantine value/condition is visible separately and cannot be resold as available units; there is no warehouse quarantine-release workflow or automatic net-realizable-value impairment assessment. Equipment return credits reverse entered asset principal; detailed depreciation/disposal closeout requires review. Legacy amount-only returns cannot safely infer eligible per-line quantities and are blocked from new quantity returns pending review.
- Supplier credits/refunds and payment references are user-recorded synthetic evidence, not validated external documents/bank statements. Supplier disputes exclude expected cash receipts; a scheduled date is an assumption, not a guarantee.
- PDF downloads use built-in Latin text with INR notation; browser Print/Save PDF is the option for Indic-script fonts. No IRN, signed QR, email/WhatsApp delivery, bank transfer, biometric attendance, statutory filing or regulated integration exists.
- Schema v2 is additive, but old version-1 builds and earlier v2 implementations cannot assume compatibility with revised credit metadata. Export before upgrading; source rollback does not automatically downgrade browser storage. There is no full-business JSON importer in this release.
- Single-browser atomic saves prevent concurrent duplicate actions; this is not a cross-device transaction coordinator. Final snapshots/reversal journals preserve local history, not cryptographic immutability. Storage quota or invalid migration fails visibly, offers the original recovery record, and blocks overwriting until an explicit reset.
- Existing large lazy WebGL chunk advisory, Zod annotation warnings and npm install-script notices remain disclosed. No measured FPS or universal device/accessibility certification claim. Final observed tests/deployment status are in the release reports.
